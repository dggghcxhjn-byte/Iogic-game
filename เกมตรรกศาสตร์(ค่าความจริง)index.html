📖 ตารางค่าความจริง

เรียนรู้พื้นฐานตรรกศาสตร์ก่อนเริ่มภารกิจ
🔹 สัญลักษณ์ที่ใช้ในเกม

¬p = นิเสธของ p
p ∧ q = p และ q
p ∨ q = p หรือ q
p → q = ถ้า p แล้ว q
p ↔ q = p ก็ต่อเมื่อ q

📊 ตารางค่าความจริง

1️⃣ การเชื่อมประพจน์ “และ” ( ∧ )

p q p ∧ q
จริง จริง จริง
จริง เท็จ เท็จ
เท็จ จริง เท็จ
เท็จ เท็จ เท็จ

2️⃣ การเชื่อมประพจน์ “หรือ” ( ∨ )

p q p ∨ q
จริง จริง จริง
จริง เท็จ จริง
เท็จ จริง จริง
เท็จ เท็จ เท็จ

3️⃣ การเชื่อมประพจน์ “ถ้า...แล้ว” ( → )

p q p → q
จริง จริง จริง
จริง เท็จ เท็จ
เท็จ จริง จริง
เท็จ เท็จ จริง

4️⃣ การเชื่อมประพจน์ “ก็ต่อเมื่อ” ( ↔ )

p q p ↔ q
จริง จริง จริง
จริง เท็จ เท็จ
เท็จ จริง เท็จ
เท็จ เท็จ จริง
💡 จำง่าย ๆ

🔹 ∧ และ → ต้องจริงทั้งคู่
🔹 ∨ หรือ → จริงอย่างน้อยหนึ่งข้อความ
🔹 → ถ้า...แล้ว → เท็จเพียงกรณีเดียว คือ จริง → เท็จ
🔹 ↔ ก็ต่อเมื่อ → ต้องมีค่าความจริงเหมือนกัน
